Archive

Every Filecoin node needs the Groth16 proving and verifying keys listed in parameters.json, about 150 GB, normally fetched from proofs.filecoin.io. ChainVault fetches each file, checks the manifest digest, and stores it on a Filecoin PDP storage provider in 1000 MiB pieces with a manifest keyed by the file's original CID.

Use

Point a node at this site instead of the default gateway. It fetches by CID as usual and verifies the digest itself, so the copy is byte-exact or rejected.
