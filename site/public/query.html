How it works

Paste a CID. The page asks the IPNI index which Filecoin storage providers hold it, and you pick one. Your browser fetches that provider's CAR directly, checks every block's hash against its CID, and hands the bytes to DuckDB running in the page. Pick another provider and run the same query: same rows, same hash.

Why

No gateway, no vendor, no server of ours. The provider proves on-chain that it still holds the data; the verification here happens on your machine. Any provider that has the CID will do.
